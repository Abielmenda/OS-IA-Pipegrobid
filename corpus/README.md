Esta carpeta tiene el "patrón de oro" o "gold standard"  usado para evaluar modelos para reconocer entidades "Name Entitity Recognition" que forman parte de los "acknowledgements" de articulos cientificos. El gold standard tiene 8 documentos que se han anotado manualmente sus 3 entidades (PER, ORG y PROJ), en el formato deseado. Véase ANNOTATION_GUIDELINES.md para más información.
